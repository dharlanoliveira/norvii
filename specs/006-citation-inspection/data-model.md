# Data Model: Citation Navigation and Inspection

## Persistence Impact

No migration is required. Existing `document_versions`, `document_units`, `retrieval_chunks`,
`sources`, and `source_revisions` remain canonical. The feature reads an exact published document
version rather than only the source's latest ready version. Answer inspection is an ephemeral
browser-session record and is never persisted.

## Citation Target

| Field | Type | Rules |
|---|---|---|
| `id` | string | Stable retrieval-chunk identifier. |
| `corpusId` | UUID | Must equal the active answer corpus before navigation. |
| `sourceId` | UUID | Must own the cited document version. |
| `documentVersionId` | UUID | Immutable `document_versions.id`; required for Feature 006 navigation. |
| `documentId` | UUID | Existing compatibility field with the same current value as `documentVersionId`. |
| `sourceRevisionId` | UUID | Immutable source revision that produced the document version. |
| `pipelineVersion` | string | Extraction pipeline provenance for inspection. |
| `unitLocator` | string | Stable legal location label. |
| `startOffset` / `endOffset` | non-negative integer | Half-open range; must be in the returned document text and within a resolved unit. |
| `excerpt` | bounded string | Faithful preserved text selected during retrieval. |
| `rank` | positive integer | Retrieval order, with no duplicate ranks in one answer. |
| `cosineDistance` | number or `null` | Raw pgvector cosine distance; lower is nearer. `null` means unavailable. |
| `sourceTitle` | string | Source identity shown in inspection; not generated by the model. |

### Citation Resolution Invariants

1. The active workspace corpus, reference corpus, request route corpus, returned document corpus,
   and returned document source must match.
2. The returned `DocumentResponse.id` must equal `documentVersionId`; a source's current latest
   document is never substituted.
3. The cited offset range must satisfy `0 <= startOffset < endOffset <= text.length` and belong to
   the resolved legal unit or its visible parent range.
4. A nested unit resolves to its visible ancestor for layout, but retains its exact target offsets.
5. Any failed invariant produces an explicit unavailable state with no substitute source content.

## Execution Measurement

| Field | Type | Owner | Meaning |
|---|---|---|---|
| `retrievalMilliseconds` | non-negative integer or `null` | Python graph | Elapsed time for the corpus-scoped retrieval call. |
| `generationMilliseconds` | non-negative integer or `null` | Python graph | Elapsed time for the model generation call. |
| `totalMilliseconds` | non-negative integer or `null` | Go public handler | Elapsed time from accepted public request to terminal event. |
| `inputTokens` | non-negative integer or `null` | Python provider adapter | Provider-reported input use only. |
| `outputTokens` | non-negative integer or `null` | Python provider adapter | Provider-reported output use only. |

`null` is always rendered as unavailable. Zero is valid only where the measuring owner reported a
genuine zero.

## Answer Inspection

| Field | Type | Rules |
|---|---|---|
| `requestId` | UUID | The terminal chat request identity. |
| `outcome` | `completed`, `abstained`, `cancelled`, or `failed` | Honest terminal state. |
| `retrieval` | object | `strategy` is initially `vector`; contains `topK`, `returnedCount`, and nullable embedding-model identifier only when already configured for safe display. |
| `evidence` | ordered citation targets | Present for completed answer inspection only. |
| `measurements` | execution measurement | Content-free data associated with this request only. |

### Lifecycle

```text
started -> evidence -> delta* -> terminal event
                                 |-- completed: answer + inspection with evidence
                                 `-- abstained/cancelled/error: safe outcome + measurements only
```

The React runtime maps a completed inspection snapshot to its Assistant UI message identifier.
Changing Chat/Source tabs retains it. Reloading, changing corpus route, or closing the session
discards it.
