# Data Model: Grounded RAG Chat

## Research request

| Field | Rules |
| --- | --- |
| `id` | Stable UUID for one request lifecycle |
| `corpus_id` | Required active enabled corpus identity |
| `question` | Non-empty normalized input within the configured POC limit; never persisted in telemetry |
| `interface_language` | `en` or `pt` |
| `status` | `started`, `retrieving`, `streaming`, `completed`, `abstained`, `cancelled`, or `failed` |
| `created_at` | Request start timestamp |

Requests are ephemeral in this feature. The identity is carried through stream events and safe
telemetry but is not a durable conversation record.

## Retrieval chunk

| Field | Rules |
| --- | --- |
| `id` | Stable UUID |
| `corpus_id` | Must match the owning source and document version |
| `source_id` | Must identify one source in the corpus |
| `source_revision_id` | Immutable captured revision |
| `document_id` | Immutable published document version |
| `unit_id` | Optional document unit; must belong to `document_id` when present |
| `ordinal` | Contiguous within one document version and chunking policy |
| `start_offset`, `end_offset` | Non-overlapping normalized text span within the complete document |
| `text` | Faithful normalized excerpt used for retrieval context |
| `text_sha256` | Hash of `text` |
| `embedding` | Fixed-dimension vector generated by the configured embedding model |
| `embedding_model`, `embedding_version` | Required reproducibility metadata |
| `created_at` | Publication timestamp |

Chunks are immutable. A source reprocess creates a new document and chunk set; older chunks remain
available for historical answer identity but are excluded from current retrieval.

## Retrieved evidence

An in-memory ranked result containing the chunk identity, corpus/source/document identity, stable
unit locator, offsets, faithful excerpt, rank, and similarity score. The retrieval application
must filter by active corpus and the source's latest published document before ranking.

## Evidence reference

The public citation target contains the immutable corpus, source, document, unit locator, offsets,
rank, and a bounded excerpt. It is not a free-form URL and cannot resolve outside the active
corpus.

## Grounded answer

An in-memory answer state contains request identity, status, streamed text, numbered evidence
references, detected citation markers, model version, and terminal outcome. A completed state is
valid only when every required factual segment has a resolvable reference. Abstained and failed
states contain no completed answer citations.

## State transitions

```text
started -> retrieving -> streaming -> completed
                         |             |
                         |             +-> cancelled
                         +-> abstained
                         +-> failed
started/retrieving/streaming -> cancelled
```

Only one terminal state is allowed. A disconnect, timeout, invalid active corpus, provider error,
or validation failure must not transition to `completed`.
